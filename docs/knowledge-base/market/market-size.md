# Market framing

This release does not claim a precise total addressable market. Most targets are private companies with incomplete contract and customer data, so multiplying public list prices by unverified customer counts would create false precision.

## Practical opportunity definition

- **TAM:** recurring spend across known SaaS workflows that can be delivered through open-source software plus optional hosting and services.
- **SAM:** the ten researched categories where customer pain, data ownership, and technical tractability overlap.
- **SOM:** the first three missions—Canny/Fider, Motion, and Dovetail—measured through verified migrations, active users, and hosted-support revenue.

## Measurement approach

Use observed migrations and replacement usage to size each category from the bottom up. Track displaced annual contract value only when adopters voluntarily provide it; never present modeled savings as audited vendor revenue.

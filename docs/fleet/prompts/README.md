These prompts are self-contained implementation handoffs for the ten SaaSassin
products. Pass one entire file to Claude from the repository root.

| Performance | [`performance.md`](performance.md) | Active now |
| Research | [`research.md`](research.md) | Design partners + security review |
| Planner | [`planner.md`](planner.md) | After Performance evidence gate |
| Creator | [`creator.md`](creator.md) | Component selection |
| Feedback | [`feedback.md`](feedback.md) | Fider maintainer direction required |
| Studies | [`studies.md`](studies.md) | Component adapter decision |
| Revenue | [`revenue.md`](revenue.md) | Vexa/governance review |
| Community | [`community.md`](community.md) | Open stack decision |
| Mail | [`mail.md`](mail.md) | Maintainer-backed foundation decision |
| Trust | [`trust.md`](trust.md) | Openlane/security review |

Each prompt requires real persistence, authorization, rules, tests, browser
verification, and deployment. None authorizes commits, pushes, or GitHub Actions.

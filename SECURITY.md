# Security policy

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/alibad/saasassin/security/advisories/new)
rather than a public issue. Include the product, the affected route or rule, and steps
to reproduce. We aim to acknowledge reports within three working days.

In scope: the hosted products at `*.saasassin.net`, this repository, and the generated
`alibad/saasassin-<product>` repositories. Please don't run automated scanners against
the hosted products or access data that isn't yours; use a self-hosted copy for testing.
